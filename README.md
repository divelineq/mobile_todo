# Руководство пользователя

## Назначение приложения
Мобильное приложение разработано для сотрудников **ООО ТД АСК** для ведения рабочих заметок во время совещаний, встреч и конференций. Приложение позволяет быстро фиксировать идеи, задачи и важную информацию в структурированном виде.

---

## Основные функции

### 1. Создание заметок
1. **Нажмите на поле ввода** "Что вы хотите сделать..."
2. **Введите текст заметки**
3. **Нажмите кнопку "+" или клавишу Enter** для сохранения
4. **Система автоматически добавляет** дату и время создания

### 2. Редактирование заметок
- **Двойное нажатие** на существующую заметку откроет режим редактирования
- **Возможность изменения** текста
- **Сохранение изменений** одной кнопкой

### 3. Удаление заметок
1. **Нажмите на значок ❌** рядом с заметкой
2. **Подтвердите удаление** во всплывающем окне
3. **Заметка будет безвозвратно удалена**

### 4. Поиск заметок
1. **Используйте верхнее поле** "Поиск задач..."
2. **Введите ключевые слова** или фразы
3. **Система мгновенно фильтрует** заметки по тексту
4. **Для очистки поиска** нажмите ✕ в поле ввода

---

## Технические особенности

### Способы хранения данных:
#### 📱 Локальное хранение в AsyncStorage
- Все заметки сохраняются на устройстве
- Данные сохраняются после перезапуска приложения
- Не требуется подключение к интернету

### Кроссплатформенность:
- ✅ **Работает на iOS и Android** через Expo Go
- ✅ **Веб-версия доступна** в браузере
- ✅ **Единый код** для всех платформ
- ✅ **Адаптивный интерфейс** под разные размеры экранов

## Как протестировать приложение

### Для научного руководителя:

#### **Способ 1: Быстрый запуск (рекомендуется)**
1. Установите на смартфон приложение **Expo Go** из:
   - **App Store** (для iOS)
   - **Google Play** (для Android)
2. Отсканируйте **QR-код**: `exp://exp.host/@ваш-аккаунт/tasknotes`
3. Приложение **запустится автоматически**

#### **Способ 2: Локальный запуск**
1. **Скачайте код с GitHub**:  
   `https://github.com/ваш-логин/tasknotes-ask`
2. **Установите зависимости**:  
   ```bash
   npm install
2. **Запуск**:  
   ```bash
   expo start или для веб версии expo start --web
